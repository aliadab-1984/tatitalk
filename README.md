# Tatitalk reference rebuild

Responsive reconstruction of the approved Tatitalk homepage reference.

## Open
Extract the ZIP, then open `index.html` in a browser. For phone testing, open the same project on the phone or use the browser's device preview in desktop developer tools.

## Responsive behavior
- Desktop: original three-column card layout.
- Tablet: two-column cards.
- Phone: single-column cards, stacked story text, mobile navigation, and full-width hero.

## Before publishing
- Replace sample parent testimonials with real, approved testimonials.
- Add the teacher's phone number and exact direct Bale/WhatsApp links.
- Login/cart are visual placeholders; no account or payment backend is connected.
- Google Fonts loads when internet is available; Tahoma is the fallback.
