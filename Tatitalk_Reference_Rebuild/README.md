# Tatitalk reference rebuild

A responsive HTML/CSS/JavaScript reconstruction based on the user's approved 1024×1536 reference image.

## Run
Open `index.html` in a browser. The page uses Google Fonts when internet is available and falls back to Tahoma.

- Replace the sample parent testimonials with real, approved testimonials.
- Add the teacher's phone number and exact direct Bale/WhatsApp links.
- The login/cart links are visual placeholders; no account or payment backend is connected.
- The hero and illustration assets are crops from the supplied reference image to preserve its visual style.
