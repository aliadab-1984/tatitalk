فایل‌های صفحه کتابخانه تاتی‌تاک

ساختار پوشه‌ها را به همین شکل داخل پروژه خود کپی کنید:
html/books.html
css/books.css
js/books.js
assets/images/ (تصاویر بنر، جلد کتاب‌ها و آواتارها)

نکته:
- صفحه به صورت مستقل طراحی شده و CSS صفحه اصلی را تغییر نمی‌دهد.
- لینک‌های منوی بالا به index.html و بخش‌های آن اشاره می‌کنند.
- برای استفاده از فونت نازنین، فایل fonts/Nazanin.ttf باید در ریشه پروژه موجود باشد.
- تصاویر بنر و جلدها از تصویر نمونه تأییدشده برش خورده‌اند؛ برای تعویض آن‌ها کافی است فایل هم‌نام را در assets/images جایگزین کنید.
